# Project Rules — Cosmic Mythology AR Explorer

Obey these permanent rules on every task:

1. **Never edit `dist/` by hand.** It is generated by `scripts/build-public.js`.
2. **Keep the heritage filter (`excludePendingCommunityReview` in `data/policy.json`) and `scripts/launch-audit.js` working.** The audit must still pass.
3. **Privacy by design:** No third-party CDNs, trackers, analytics, or external fonts. Everything stays self-hosted.
4. **The Supabase anon key in the page is fine (public by design).** Never add a `service_role` key anywhere.
5. **Keep Pointer Events (touch and mouse) on the globe and planisphere.**
6. **Until the modularization step, preserve script order in `index.html`.**
7. **One task per branch, small commits, and show a plan listing the files to touch before editing.**
8. **After each change, verify in the browser agent and show screenshots at 360px and 1440px widths.**
9. **If something is unclear or risky, stop and ask instead of guessing.**
10. **Run `node scripts/validate-content.js`, `npm test` (or `npm.cmd test` on Windows) and a build with `SITE_URL` set before declaring any task done.**
11. **After ANY edit to index.html or audio.html, run `npm.cmd run build` with SITE_URL set plus the build-guard test. If a transform stops matching, fix the transform in the same commit.**
12. **This machine runs Windows and PowerShell: use npm.cmd instead of npm, and use forward slashes in script paths.**
